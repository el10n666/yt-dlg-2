# Скачиватель видео и аудио для Windows: дизайн

Дата: 2026-11-18. Статус: ждёт одобрения.

## Зачем
Простое приложение для мамы: вставила ссылку, нажала кнопку, получила видео или аудио. Владелец (разработчик) обновляет приложение удалённо, без визитов.

## Цели
- Один установщик `.exe` для Windows, ничего дополнительно ставить не нужно (ни Python, ни yt-dlp, ни ffmpeg).
- Один экран: поле ссылки, переключатель «Видео / Только аудио (MP3)», кнопка «Скачать», список загрузок с прогрессом.
- Папка по умолчанию: «Загрузки». Настроек по умолчанию нет.
- Автообновление самого приложения через GitHub Releases.
- Автообновление yt-dlp при каждом запуске (сайты ломают скачивание каждые 1-2 недели).
- Скрытый раздел «Дополнительно»: cookies из браузера, прокси, плейлисты.

## Не цели
- Обход DRM (Widevine и подобное). Не делается и не закладывается.
- Публичная раздача (поэтому лицензии ffmpeg проверяются только при смене плана).
- macOS и Linux, мобильные версии.
- Планировщик, конвертер, редактор видео.

## Антицели (провал, даже если технически работает)
- Мама видит окно с ошибкой на английском или консольный вывод.
- Приложение перестаёт скачивать из-за устаревшего yt-dlp и не чинится само.
- Для обновления нужно что-то делать вручную на её компьютере.

## Подходы
1. **Electron + electron-builder + electron-updater (выбран).** Установщик `.exe`, бинарники yt-dlp и ffmpeg внутри, готовый механизм обновления через GitHub. Минус: размер установщика около 100+ МБ.
2. Форк yt-dlg (Python/wxPython) + PyInstaller. Ближе к оригиналу, но тяжелее, старый интерфейс, автообновление пришлось бы писать самому. Отклонён.
3. Tauri. Установщик меньше, но нужен Rust и ручная работа с внешними бинарниками. Выигрыш мал. Отклонён.

Выбор подхода и мотивация записаны как решение ассистента, пользователь возражений не высказал.

## Решения (выбраны ассистентом, можно поправить)
- yt-dlp и ffmpeg: готовые `.exe`, кладутся в ресурсы приложения. yt-dlp при запуске обновляется командой `-U`, обновлённая копия хранится в папке данных пользователя, чтобы не требовать прав администратора.
- Обновления приложения: GitHub Releases, публикация через `electron-builder`. Репозиторий потребуется создать на аккаунте владельца (нужно имя аккаунта).
- Ошибки показываются по-русски простыми фразами, технические подробности спрятаны.
- Язык интерфейса: русский.

## Оставлено исполнителю
- Точный внешний вид, иконка, название приложения.
- Структура кода (минимальный main/renderer на Electron).
- Подбор версий ffmpeg-сборки для Windows.
- Подписывание установщика не делается (Windows SmartScreen предупредит при первом запуске, это нужно объяснить маме).

## Риски и меры (приоритет: у мамы не должно быть проблем)
GitHub-аккаунт владельца: `el10n666`. Репозиторий публичный (иначе в приложение пришлось бы зашить токен доступа, это небезопасно).

| Риск | Мера |
|------|------|
| SmartScreen на неподписанном `.exe` | Первый установщик ставит владелец сам (лично или удалённо), мама его не скачивает из браузера. Обновления приложение скачивает само, SmartScreen при них не срабатывает. Платная подпись кода: запасной вариант, решаем только если понадобится раздача шире. |
| Права администратора / UAC | Установка только для текущего пользователя (NSIS, `perMachine: false`), без запросов UAC. |
| Антивирус ругается на yt-dlp/ffmpeg | Бинарники только с официальных релизов (yt-dlp: github.com/yt-dlp/yt-dlp, ffmpeg: проверенная Windows-сборка), сверка SHA-256 перед использованием. Если Defender всё же блокирует, владелец один раз добавляет папку приложения в исключения при установке. |
| Обновление yt-dlp ломает скачивание | Только стабильные релизы. Последняя рабочая копия хранится рядом, при сбое обновления или тестового запуска (`--version`) приложение откатывается на неё. Вшитая в установщик копия служит последним запасом. |
| Сайт сломал экстрактор, а исправления ещё нет | Понятное сообщение по-русски («Этот сайт временно не поддерживается, попробуйте позже»), приложение не падает. |
| Плохое обновление самого приложения | Релизы выпускаются только после проверки на чистой Windows. Авто-установка только после закрытия приложения (`autoInstallOnAppQuit`), не посреди скачивания. Предыдущий релиз остаётся в GitHub Releases для быстрого отката. |
| Нет интернета / нет места на диске / неверная ссылка | Явные проверки до запуска yt-dlp и сообщения по-русски. |
| Поддержка на расстоянии | Кнопка «Сообщить о проблеме» сохраняет лог на рабочий стол, мама отправляет файл владельцу. Телеметрии нет. |
| Контент с DRM | Не поддерживается. Приложение просто сообщит, что скачать нельзя. |
